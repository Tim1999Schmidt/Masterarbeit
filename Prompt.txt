In einer vorausgehenden Arbeit wurde ein STM32 Projekt für einen STM32F401RET6 entwickelt, mit dem eine Temperaturregelung mittels Peltierelement realisiert wird. Das Projekt hierfür befindet sich in dem angehängten temperature_driver_sw Zip-Ordner. Nun soll diese Temperaturregler in einem neuen Projekt integriert werden. Als Grundlage wurde ein neuer Projektordner erstellt (siehe Anhang BM Zip-Ordner) , bei dem die Mikrocontrollerkonfiguration im IOC-File bereits vorgenommen wurde. In dem neuen Projekt kommt es zu einigen Änderungen was bei der Integration der temperature_driver_sw berücksichtigt werden muss: 1.) in dem neuen Projekt wird als Mikrocontroller der STM32C051K6T6 verwendet, damit haben sich auch die Pinbelegungen geändert (siehe IOC-File BM), der Code muss daher auf die neue Pinbelegung angepasst werden. 2.)  In den Ausgangssoftware wurde eine Autokalibrierung des Reglers implementiert was den urspünglichen Code unnötig aufbläht, die Autokalibrierung kann daher komplett verworfen werden. 3.) Die Software temperature_driver_sw wurde komplett im main geschrieben, was die Übersichtlichkeit und Lesbarkeit erschwert. Dieser sollte auf mehrere Files aufgeteilt werden, hierbei sollte ein extra File für Strommessung, Temperaturmessung und PID-Regelung erstellt werden. 4.) Zusätzlich zum Ausgangscode muss eine Kommunikationsschnittstelle über I²C implementiert werden über die der Mikrocontroller mit dem Master kommunizieren kann. Der Mikrocontroller auf dem die Software läuft soll nämlich basierend auf den Einstellungen die er vom Masterboard erhält die Temperatur regeln.
